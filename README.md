## 模拟计算器
## 项目介绍
该项目是一个基于 HTML、CSS 和 JavaScript 开发的模拟 Windows 计算器网页应用，具备基本的算术运算功能（加减乘除）、正负号转换、百分比计算，还支持运算历史记录的查看、调用和隐藏 / 显示切换，采用逆波兰表达式算法处理运算优先级，确保计算准确性。
## 功能列表
基础算术运算：支持加、减、乘、除运算，自动处理运算符优先级
特殊计算：正负号切换（±）、百分比转换（%）
历史记录：保存最近 10 条运算记录，点击记录可快速调用结果，支持历史记录的显示 / 隐藏切换
界面交互：清晰的按钮布局，hover 效果增强操作体验，结果自动格式化（去除多余小数位）
## 使用方法
点击数字键（0-9）和小数点（.）输入数值
点击运算符键（+、-、×、÷）选择运算类型
点击 “±” 切换当前数值正负，点击 “%” 将当前数值转换为百分比
点击 “=” 执行计算并显示结果，结果会自动保存到历史记录
点击 “C” 清空当前输入，点击 “历史” 按钮切换历史记录的显示 / 隐藏状态
点击历史记录项可将结果快速填入输入框
